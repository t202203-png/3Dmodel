# 존중의 언어 갤러리

혐오 표현 개선 캠페인 학생 포스터 5점을 3D 전시장에서 둘러보는 웹페이지입니다.

- 실행: `index.html`을 웹 서버로 열기 (예: `python3 -m http.server` 후 http://localhost:8000)
- 조작: 드래그로 둘러보기, W·A·S·D/방향키로 걷기, 바닥을 누르면 이동, 작품을 누르면 감상
- 작품 정보 수정: `index.html`의 `WORKS` 배열에서 제목·주제·설명·학생 이름(`student`)을 고치면 됩니다.
- 작품 추가: `works/` 폴더에 이미지를 넣고 `WORKS`와 `SLOTS`(벽 위치)에 한 줄씩 추가합니다.
